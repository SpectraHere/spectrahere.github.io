What this page is

It's one file: index.html. Everything you see — the words, the colors, the button below — lives in that single file. Open it in any text editor, change something, save it, and refresh the page to see what happened.

A few things worth trying

  • Change the words. Find the sentence you're reading right now inside the file and rewrite it.
  • Change the color. Near the top of the file there's a line that says --accent: #3e6259; — swap the code after the colon for any hex color and save.
  • Add a new section. Copy one of the <section> blocks, paste it below, and change what's inside.
